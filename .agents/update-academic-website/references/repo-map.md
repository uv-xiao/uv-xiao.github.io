# Repository Map

## Site Content

- `_bibliography/papers.bib`: publication database consumed by Jekyll Scholar.
- `_projects/*.md`: project pages. Use `related_papers` to render bibliography cards.
- `_pages/about.md`: home/about page and current research list.
- `_pages/cv.md`: website CV page wrapper; `cv_pdf: CV.pdf` links `assets/pdf/CV.pdf`.
- `_data/cv.yml`: structured data rendered on the website CV page.
- `assets/pdf/`: local publication PDFs and generated `CV.pdf`.

## CV Source

- `_cv_latex/CV.tex`: LaTeX source for the PDF CV.
- `_cv_latex/Makefile`: builds and moves `CV.pdf` to `../assets/pdf/CV.pdf`.
- `_cv_latex` may be a Git submodule. Use `git -C _cv_latex status --short` to inspect nested changes.

## Required Commands

```bash
make -C _cv_latex
pixi run build
pdftotext assets/pdf/CV.pdf -
```

## Common Pitfalls

- The LaTeX CV may need portable CJK font handling on Linux if a macOS-only font is configured.
- Publication pages are generated by Jekyll Scholar during `pixi run build`; do not edit `_site` directly.
- The repository instructions prefer `pixi` tasks over direct Jekyll commands for normal verification.
