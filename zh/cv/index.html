研究方向

我当前的研究聚焦面向新型 AI 芯片上大模型系统的智能体基础设施，研究智能体如何完成算子功能实现、芯片架构感知性能优化与工具链自动开发。这一方向从两个维度驱动大模型系统：一方面提升新芯片上的模型服务效率，另一方面沉淀开发数据与 trajectory，增强后续 coding 与系统智能体能力。

大模型智能体基础设施。 我当前的工作围绕新芯片上大模型基础设施的真实生命周期构建智能体：算子功能实现、架构感知性能优化与工具链自动开发。核心系统问题是：智能体流程如何连接软件意图、编译器/运行时约束、芯片特定优化机会，以及可复用的开发 trajectory。

编译器与运行时底座。 既有系统工作提供了智能体可操作的系统界面。IntelliC (GitHub) 研究面向人与智能体协作的可检查编译表示。PTO Runtime (GitHub) 面向 Ascend 芯片和灵衢 SuperPod 执行编译后的任务图。Hive (preprint) 将多智能体大模型负载暴露给推理基础设施，Spine 研究跨设计意图、架构、编译器、硬件与执行证据的有界智能体协同设计。

软硬件协同基础。 我此前在编译器、e-graph、硬件综合与架构定制上的论文构成了当前智能体方向的技术基础。ISAMORE (DOI) 和 EggMind (preprint) 展示了形式化搜索与大模型引导搜索如何组织优化过程。Hector (DOI)、Cement (DOI)、Clay (DOI)、Cayman (DOI)、APS (DOI, GitHub)、Aquas (preprint) 与 SkyEgg (preprint) 提供了 IR、综合、运行时与协同设计方法，使智能体决策落在真实系统产物上。
